# ADR-0001：模块化单体和本地优先

- 状态：Accepted
- 日期：2026-09-11

## 背景

V0.1 的主要风险是数据契约、时间准确性和模型质量，而不是服务拆分或团队协作。原始素材通常体积大且敏感，用户也需要在本地处理数小时视频。

## 决策

使用本地运行的 Python 模块化单体。以 `domain`、`application`、`ports`、`adapters` 分隔模型、媒体库、存储和用例。默认不上传原始视频、音频或派生帧；远程推理必须是显式 provider。

## 后果

- 第一阶段可以专注于 CLI、可恢复 pipeline 和契约测试。
- 具体模型和基础设施可以替换。
- 暂不引入微服务、Celery、Kafka 或云数据库。
- 如果未来需要 UI 或多进程服务，可以在 ports 上增加 API，而不改变 domain。
