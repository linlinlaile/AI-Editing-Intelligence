# V0.1 产品定义

## 1. 产品目标

V0.1 为有大量原始素材的创作者提供一个本地素材智能层，让用户无需从头浏览数小时视频，就能找到当前剪辑位置可能需要的镜头。

它不是 NLE，而是：

```text
素材理解 → Shot 级检索 → 当前上下文下的候选推荐 → 未来导出到专业 NLE
```

## 2. 目标用户和 Job

目标用户：

- 独立剪辑师
- 小型创作者团队
- 旅行、纪录片、活动、婚礼、品牌视频创作者

核心 Job：

> 我不想重新浏览所有素材；我想快速找到适合当前剪辑位置的镜头，并知道系统为什么这样推荐。

## 3. 两个核心入口

### Search by Intent

用户用自然语言描述目标镜头，例如：

> 找湖边夕阳、没有人物、远景、缓慢横移、比较平静，适合放在这一段结尾的镜头。

系统应将请求拆成：

- 正向语义：湖边、夕阳、平静
- 结构/摄影约束：无人、远景、缓慢横移
- 角色或编辑意图：段落结尾
- 可选负条件：人物、严重抖动、过曝、重复镜头

结果必须包含 Shot、时间范围、预览证据和分项匹配理由。

### Search by Context / Find Next Shot

用户选择当前 Shot，系统返回多个候选，并说明：

- 同一事件或同一主体的可能性
- 动作是否连续
- 运动方向是否匹配
- 景别是否形成连续、推进或反差
- 视线关系
- 情绪连续或反差
- 视觉/运动相似度
- 画质、重复度和声音风险

推荐必须注明 `edit_intent`。至少支持 `continuity`、`contrast`、`cutaway` 三种策略；未指定时默认为 `continuity`，同时允许返回少量不同策略的候选。

## 4. V0.1 的能力范围

### 必须支持的描述维度

- 内容：subject、object、location、action
- 摄影：shot size、camera angle、camera motion
- 人物运动：进入/离开、左右方向、接近/远离、视线方向
- 情绪：valence、arousal、coarse mood
- 质量：blur、shake、exposure、occlusion
- 声音：speech、music、ambient

其中人物运动、视线、情绪和部分运镜允许返回 `unknown`，并必须保留 coverage 和证据。V0.1 的“支持”指数据契约和分析接口支持，不代表每类素材都能可靠判断。

### 最小闭环

```text
video
→ ingest
→ shot detection
→ frame/window sampling
→ semantic analysis
→ Semantic Timeline
→ intent retrieval
→ experimental next-shot ranking
```

## 5. 明确不属于 V0.1

- 完整 NLE 或复杂 timeline editor
- 自动字幕编辑器或 transcript 驱动剪辑
- 自动 rough cut / fine cut
- AI 视频、图片、音乐生成
- Motion Graphics、调色
- 团队协作、手机端
- 云端素材库
- Scene/Event 自动推理作为核心前置流程

## 6. 质量和评估

V0.1 必须同时建设评估集，而不是先做 demo 再寻找标准。评估集至少包含：

- 一组带 Shot boundary 标注的素材
- 一组自然语言意图与相关 Shot 标注
- 一组当前 Shot → 候选 Shot 的编辑师 pairwise preference
- 失败案例：VFR、甩镜、闪光、遮挡、远景人物、弱光和音画混合

指标按能力选择：

- Shot detection：precision / recall / boundary tolerance
- 语义特征：分类 F1、回归误差、置信度校准
- 检索：Recall@K、nDCG@K、负条件违例率
- 下一镜头：pairwise preference、Top-K acceptance、策略覆盖率
- 系统：可恢复性、重复运行一致性、首次分析和查询延迟

## 7. 用户隐私边界

默认本地处理原始视频、代表帧、音频和推理中间产物。远程推理属于独立 provider，必须由用户显式启用，并明确传输的是原始视频还是其派生帧/音频。
